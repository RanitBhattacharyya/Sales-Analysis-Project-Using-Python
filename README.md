# Sales-Analysis-Project-Using-Python

Product Sales Analysis using Python

I recently completed a hands on data analysis project using Python, where I explored sales data to uncover key business insights and customer purchasing patterns. The goal was to analyze product performance, customer demographics, and sales trends to better understand what drives revenue.

The project began with importing and cleaning the dataset using Pandas, removing unnecessary columns, handling missing values, and converting data types for consistency. 

Once the data was structured properly, I performed exploratory data analysis (EDA) using Matplotlib and Seaborn to visualize trends across gender, age group, state, marital status, and occupation.

Through this process, I identified that married women aged 26–35 from Uttar Pradesh, Maharashtra, and Karnataka, particularly those working in IT, healthcare, and aviation, were the most frequent buyers. The top-selling product categories were Food, Clothing, and Electronics, indicating strong demand in those segments.

This project strengthened my understanding of how Python can be used to clean raw data, identify patterns, and present insights visuals that are crucial for data driven decision making.
